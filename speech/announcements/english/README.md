# English announcements

Made with `speech/generate_announcements.py`, one folder per voice (`female/`,
`male/`), with the same file names as the German set. The lead-in is
`next_dance.mp3` here too ("Next dance"). Every clip that is missing here
is played from `../german/`.

The hall EQ is baked in like in the German set (`tools/announce_eq.py`,
preset recorded in each voice's `eq_applied.md`); the untouched recordings are
in `original/`.
