# DanceSport Player for Windows

(Deutsch: siehe unten.)

## Install with the setup

1. Double-click `DanceSport-Player-…-setup.exe`.
2. Confirm *Install for all users*: Windows asks for administrator rights
   once, for the setup; the app itself runs without them. Or pick *Install for
   me only*, which needs no administrator rights.
3. Pick the folder the app goes in. Proposed is
   `C:\Program Files\DanceSport-Player` (for you only:
   `%LOCALAPPDATA%\Programs\DanceSport-Player`).
4. Tick *Create a desktop shortcut* if you want one. The app is in the Start
   menu either way.

An update is installed the same way, over the old one: the setup proposes the
folder the app is already in and keeps the settings, playlists and database
there. *Apps & features* uninstalls it; that also leaves your data behind.

## Or unzip the folder

1. Unzip the whole download: right-click the .zip, *Extract All...*. Do not
   start the app from inside the zip window.
2. Put the `DanceSport-Player` folder wherever you like, for example in your
   Documents or on a USB stick.
3. Double-click `DanceSport-Player.exe`.

The first start may show **"Windows protected your PC"**. The app is not signed
with a paid certificate, so SmartScreen does not know it yet. Click
**More info**, then **Run anyway**. This is asked only once.

ffmpeg is included; nothing else needs installing.

Settings and playlists are kept in the app's folder. Where
Windows forbids writing (`C:\Program Files`), they go to
`%LOCALAPPDATA%\DanceSport-Planner-Player` instead.

# DanceSport Player für Windows

## Mit dem Setup installieren

1. `DanceSport-Player-…-setup.exe` doppelklicken.
2. *Installation für alle Benutzer* bestätigen: Windows fragt einmal nach
   Administratorrechten, für das Setup; die App selbst läuft ohne. Oder *Installation
   nur für Sie* wählen, das braucht keine Administratorrechte.
3. Den Ordner wählen, in den die App kommt. Vorgeschlagen ist
   `C:\Program Files\DanceSport-Player` (nur für dich:
   `%LOCALAPPDATA%\Programs\DanceSport-Player`).
4. *Desktop-Symbol erstellen* anhaken, wenn gewünscht. Im Startmenü steht
   die App in jedem Fall.

Ein Update wird genauso installiert, über das alte: Das Setup schlägt den
Ordner vor, in dem die App schon liegt, und behält die Einstellungen,
Playlisten und die Datenbank dort. Deinstallieren geht über *Apps & Features*;
auch dabei bleiben die eigenen Daten liegen.

## Oder den Ordner entpacken

1. Den ganzen Download entpacken: Rechtsklick auf die .zip, *Alle
   extrahieren...*. Die App nicht aus dem Zip-Fenster heraus starten.
2. Den Ordner `DanceSport-Player` an einen beliebigen Ort legen, zum Beispiel
   in die Dokumente oder auf einen USB-Stick.
3. `DanceSport-Player.exe` doppelklicken.

Beim ersten Start kann **"Der Computer wurde durch Windows geschützt"**
erscheinen. Die App ist nicht mit einem kostenpflichtigen Zertifikat signiert,
deshalb kennt SmartScreen sie noch nicht. Auf **Weitere Informationen** klicken,
dann auf **Trotzdem ausführen**. Das wird nur einmal gefragt.

ffmpeg ist dabei; sonst muss nichts installiert werden.

Einstellungen und Playlisten liegen im Ordner der App. Wo Windows
das Schreiben verbietet (`C:\Program Files`), landen sie stattdessen in
`%LOCALAPPDATA%\DanceSport-Planner-Player`.
